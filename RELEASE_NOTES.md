## DocScanner v0.5.63

- ⚙️ New native library **libds_scannercore.so** — DocScanner's own C++ scanner core (written for this app, no third-party code)
- ✂️ Auto crop of imported page photos (paper region) now runs natively: faster on large photos
- ☀️ Scanner-style Enhance (white paper, dark text, no shadows) now runs natively — much faster on big pages; the previous Dart version stays as an automatic fallback
